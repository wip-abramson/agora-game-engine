name: CourierQuoteProtocol
description: This protocol is for requesting a delivery quote from a courier service, providing pickup, drop-off, weight, and optionally a target URL, and receiving a price and ETA in response.
multiround: false
---

**Protocol Description:**

This is a single-message protocol where a client sends a JSON string containing delivery request parameters, and the service responds with a JSON string containing the quote information.

**Request Format:**

A JSON string with the following structure:
```json
{
  "pickup": "string",
  "dropoff": "string",
  "weight_kg": "number",
  "target": "string (optional)"
}
```

- `pickup`: The pickup address (string, required)
- `dropoff`: The drop-off address (string, required)
- `weight_kg`: The parcel weight in kilograms (number, required)
- `target`: Optional URL of the target system (string, optional, may be ignored)

**Response Format:**

A JSON string with the following structure:
```json
{
  "price_gbp": "number",
  "eta_minutes": "integer"
}
```

- `price_gbp`: The price in British Pounds (float)
- `eta_minutes`: Estimated time of arrival in minutes (integer)

**Usage:**

- The sender serializes the request object to a JSON string and sends it.
- The receiver parses the JSON string, processes the request, and returns a JSON string response.
- Only one message is sent and one received.

def run(task_data):
    """
    Send a delivery quote request to the courier service and return the quote.
    
    Args:
        task_data: Dictionary containing pickup, dropoff, weight_kg, and optional target
        
    Returns:
        Dictionary with price_gbp (float) and eta_minutes (int)
    """
    # Prepare the request payload
    request_payload = {
        "pickup": task_data["pickup"],
        "dropoff": task_data["dropoff"],
        "weight_kg": task_data["weight_kg"]
    }
    
    # Add target if provided
    if "target" in task_data:
        request_payload["target"] = task_data["target"]
    
    # Convert to JSON string
    request_json = json.dumps(request_payload)
    
    # Send to server and get response
    response_json = send_to_server(request_json)
    
    # Parse the response

        response_data = json.loads(response_json)

import json

def run(query):
    try:
        data = json.loads(query)
    except json.JSONDecodeError as e:
        raise ValueError(f"Invalid JSON: {e}")
    if not isinstance(data, dict):
        raise ValueError("Request must be a JSON object")
    # check required fields
    for field in ['pickup', 'dropoff', 'weight_kg']:
        if field not in data:
            raise ValueError(f"Missing required field: {field}")
    pickup = data['pickup']
    dropoff = data['dropoff']
    weight_kg = data['weight_kg']
    if not isinstance(pickup, str) or not isinstance(dropoff, str):
        raise ValueError("pickup and dropoff must be strings")
    if not isinstance(weight_kg, (int, float)):
        raise ValueError("weight_kg must be a number")
    # optional target ignored
